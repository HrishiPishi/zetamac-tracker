# zetamac tracker

i made this because i use zetamac a lot and got annoyed that it doesnt save anything

so this just tracks my scores and shows a little dashboard

## what it does

- saves scores from zetamac
- shows my best score each day
- counts how many times i played
- shows averages
- shows my best score ever
- has some charts so i can see if im getting better
- lets me export/import the data in case chrome does something stupid

## why

i was practicing mental math and wanted to know if i was actually improving or just gaslighting myself

zetamac is really good but it doesnt really give you stats over time so i made this

## how to use it

download or clone this

go to

chrome://extensions

turn on developer mode

click load unpacked

pick this folder

then go play zetamac like normal

## privacy

it just saves stuff in chrome locally

nothing gets sent anywhere

## also

this does not solve the problems or play for you

it just tracks the score after you play
